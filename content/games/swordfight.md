This is technically the first video game I have ever developed. I made for CMU CS Academy’s game contest in high school during freshman year of high school. 

The game was a simple overhead swordfighting game, where two players can each move around and perform a simple attack. Because the code runner would only render images and receive input, there was no time. As a result, the game required either holding or spamming a key (I forget which) to increment the time. I recall making the project in one or maybe two class periods in about 300 lines of (repetitive) code.

I ended up winning 2nd place for Module 3 of CMU's CS Academy. I recall that 1st place created a Perry the Platapus platformer (with time!), which was so much better than my project. Regardless, I am still proud.

I no longer have any of the source code or even any proof of this game's existance besides these images.
